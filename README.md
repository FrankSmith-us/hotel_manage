# 悦栖运营（YueQi Ops）— 连锁酒店内部日常业务管理系统

专为多门店连锁酒店打造的日常内部运营管理系统，重点聚焦 **HR 人力资源全流程** 与 **多级报销风控及财务核销闭环**。

## 核心业务能力

### 1. 报销与财务协同（核心亮点）
- **多级动态审批路由**：按门店、申请人角色、金额及预算状态自动路由，**无需财务前置核算，总经理审批通过后直接由财务付款核销**：
  - 门店员工 `<= ¥1,000`（预算内）：`店长 → 集团总经理 → 财务付款`
  - 门店员工 `> ¥1,000` 或触发**超预算风控**：`店长 → 区域经理 → 集团总经理 → 财务付款`
  - 门店店长：`区域经理 → 集团总经理 → 财务付款`
- **实时风控校验**：提交前实时预览并拦截 **门店月度分科目超预算** 与 **重复发票号**，支持退回修改重提（完整保留审批日志）、一审前撤回、驳回。
- **发票附件上传与预览**：支持图片/PDF 发票凭证上传与弹窗放大预览。
- **门店备用金与借款冲销**：申请备用金/差旅借款 → 审批 → 财务放款 → 报销单关联抵扣冲销（防止多单重复占额）→ 财务打款核销后自动结算借款余额。
- **财务打款核销与预算报表**：待打款核销队列（支持批量打款流水登记）、门店月度预算执行率监控与调整、费用统计图表与 CSV 导出。

### 2. HR 人力资源全流程
- **组织架构与员工档案**：总部 — 大区 — 门店三级架构，员工入转调离生命周期记录，**酒店健康证与劳动合同 30 天内到期自动预警**。
- **酒店轮班排班**：按周展示早/中/晚/夜班四班倒排班矩阵，支持**跨店支援调派**。
- **请假与加班审批**：年假、病假、事假、调休、加班审批流，与薪资核算联动。
- **月度薪资核算台账**：一键自动核算当月工资（底薪 + 夜班天数×津贴 + 加班费 - 病事假扣款 + 绩效奖金 - 社保公积金），支持锁账与 CSV 导出。
- **补编与招聘入职**：门店补编审批、候选人面试跟进、Offer 候选人**一键办理入职**（自动建档并开通登录账号）。

## 技术栈
- **前端**：React 18 + Vite 6 + TypeScript + Tailwind CSS + Recharts + Lucide Icons
- **后端**：Node.js 24 + Express + TypeScript + Zod + JWT + Multer + bcryptjs
- **数据库**：
  - **生产主库**：MySQL 8.0（`mysql2` 连接池，完整 `server/db/mysql/schema.sql` 与 `docker-compose.yml`）
  - **本地免安装演示模式**：Node 24 内置 `node:sqlite`（通过统一 `DbAdapter` 抽象切换，100% 字段兼容）

## 快速启动

### 方式一：本地免安装演示模式（推荐快速体验）
```bash
npm run install:all
npm run dev:demo
```
- 前端地址：http://localhost:5173
- 后端地址：http://127.0.0.1:3001

### 方式二：MySQL 8.0 生产模式（Docker Compose）
```bash
docker compose up -d
cp .env.example .env
npm run install:all
npm run db:init
npm run db:seed
npm run dev
```
